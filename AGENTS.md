# Bucky public source snapshot

Read README.md before using this source. This repository is an intentionally archived, manually reviewed distribution snapshot. It does not accept contributions or automatically synchronize from a development checkout.

Keep recordings, transcripts, history, preferences, credentials, runtimes, models and built apps outside Git. Never copy internal notes, original repository history or device-specific paths into a future snapshot. Review every file and image metadata before publication. Keep speech processing local.

Validate a future source snapshot with scripts/build.sh using an isolated BUCKY_APP_PATH, focused history and shortcut checks, and tests/recording_timer.py. Engine changes also require synthetic tests/smoke.py. Do not claim synthetic tests prove physical microphone, paste or mouse behavior. Do not rebuild or launch an existing installed app as part of a publication check.
